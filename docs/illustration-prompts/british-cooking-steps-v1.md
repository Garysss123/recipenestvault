# British cooking step illustration provenance

Prompt set: `british-cooking-steps-v1`

All process illustrations in this set are original non-photorealistic assets generated with OpenAI image generation for Recipe Nest Vault. The source sheets use the existing Recipe Nest Vault warm-ivory ink-and-gouache cooking illustration as a style reference only. Each panel maps one-to-one to the recipe method state, contains no people or hands, carries no text or logos, and is excluded from recipe structured-data photography.
