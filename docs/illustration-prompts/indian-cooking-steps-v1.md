# Indian cooking step illustrations v1

Generated on 2026-09-04 with the built-in OpenAI `image_gen` tool. The visual reference was `assets/recipes/illustrations-generated/bibimbap/step-01.png` so this collection stays in the same Recipe Nest Vault illustration family as the existing Chinese, Japanese, Korean, Thai, and Taiwanese pages.

## Shared prompt contract

Each recipe requested one exact 3 × 3 process sheet. Used panels follow the recipe's natural step order from left to right and top to bottom; unused cells remain blank warm-ivory paper. Every prompt required border-free warm-ivory textured paper, crisp fine ink contours, restrained gouache shading, natural food colours, consistent scale and lighting, and a clean overhead-to-three-quarter culinary view.

The following were prohibited in every sheet: hands, fingers, arms, people, sleeves, faces, body parts, captions, numbers, logos, watermarks, photorealism, floating tools, decorative borders, flags, regional motifs, and an India-themed illustration palette. The finished dish appears only in the final used panel. India-specific colour is implemented only by the page UI.

The per-panel subject clauses were written from the English instruction title and body for each recipe in `src/indian-recipes-a.mjs` through `src/indian-recipes-e.mjs`. Source sheets are saved under `assets/recipes/illustration-sheets-generated/indian/`; deterministic 1672 × 941 crops are generated by `scripts/generate-indian-illustration-sets.mjs` and saved under `assets/recipes/illustrations-generated/<recipe-id>/`.

## Reviewed assets

The 21 source sheets cover butter chicken, palak paneer, chana masala, dal tadka, rajma masala, aloo gobi, baingan bharta, Hyderabadi chicken biryani, masala dosa, idli sambar, vada pav, pav bhaji, pani puri, samosa, vegetable pakora, tandoori chicken, rogan josh, Goan fish curry, butter naan, gulab jamun, and rice kheer.

The first tandoori-chicken sheet was rejected because a hand appeared in its preparation panel. The replacement prompt specified unattended scored chicken on a tray with no knife or body part, and repeated the no-hands constraint for each cooking panel. Only the corrected sheet is saved and hashed in the published manifest.

Run `node scripts/generate-indian-illustration-sets.mjs` after an approved sheet changes, then inspect `node scripts/indian-illustration-contact-sheet.mjs` before running `npm run audit:indian-drafts`.
