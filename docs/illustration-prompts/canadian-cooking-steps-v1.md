# Canadian cooking-step illustration set

This is the versioned prompt-set index for `canadian-cooking-steps-v1`. The full recipe-by-recipe prompts, panel ordering and visual style are recorded in [canadian-prompts.md](./canadian-prompts.md) and [canadian-prompts.json](./canadian-prompts.json). Each image is a warm-ivory, fine-ink and restrained-gouache 2D cooking illustration, separately generated for one Canadian recipe and mapped to its reviewed 3×3 panel grid.
