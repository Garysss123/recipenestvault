# Brazilian cooking step illustration provenance

Prompt set: `brazilian-cooking-steps-v1`

All process illustrations in this set are original non-photorealistic assets generated with OpenAI image generation for Recipe Nest Vault. The source sheets use the established warm-ivory ink-and-gouache cooking illustration language: fine charcoal contours, restrained translucent colour washes, sparse hand-drawn objects and subtle handmade paper texture. Each panel maps one-to-one to the exact Brazilian recipe method state, contains no people or hands, carries no text or logos, and is excluded from recipe structured-data photography. The full panel prompts and reviewed crop grids are recorded in `brazilian-prompts.json`.
