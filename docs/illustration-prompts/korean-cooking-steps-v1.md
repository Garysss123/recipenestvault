# Korean cooking-step illustration prompt set v1

Generated with the built-in OpenAI `image_gen` tool on 2026-08-30.

Each asset uses the recipe's English step title and full English instruction body as the primary request, plus these shared constraints:

- refined hand-drawn watercolor and colored-pencil editorial cooking illustration;
- warm off-white textured paper, clean 16:9 landscape composition and restrained dusty-pink accents;
- show only the exact ingredients, cookware, action, texture, quantity and doneness for that cooking stage;
- no people, hands, text, labels, logos, watermarks, unrelated ingredients or premature finished dish;
- physically plausible cookware and utensils, with no duplicated tools;
- final real-food appearance remains represented only by the separately licensed finished-dish photograph.

Style references: the approved Recipe Nest Vault `onigiri/step-01.png` and `mapo-tofu/step-03-brown-pork.png` illustrations. Targeted correction generations add explicit ingredient-form, count or timing constraints when visual review rejects an initial result. Every final Korean source PNG was reviewed against its written step before its SHA-256 hash was pinned.
